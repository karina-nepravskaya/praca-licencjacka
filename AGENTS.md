# Instrukcje dla agentów

Przed rozpoczęciem zadania wybierz i przeczytaj odpowiedni skill. Nie ładuj wszystkich bez potrzeby.

- Zmiany w plikach, kompilacja, porządkowanie repozytorium lub kontrola spójności: `.agents/skills/manage-thesis-repository/SKILL.md`.
- Uruchamianie, naprawa lub interpretacja notebooków, tabel i wykresów: `.agents/skills/analyze-ionization-data/SKILL.md`.
- Formułowanie wniosków fizycznych na podstawie wyników: `.agents/skills/interpret-ionization-results/SKILL.md`.
- Pisanie lub redakcja `main.tex`, rozdziałów, podpisów i bibliografii: `.agents/skills/write-physics-thesis/SKILL.md`.

Jeżeli zadanie obejmuje kilka etapów, stosuj skille w kolejności:
analiza danych → interpretacja fizyczna → redakcja tekstu → kontrola repozytorium.

Nie zakładaj, że README zastępuje instrukcje wybranego skilla. Pliki notebooków i aktualne wyniki są źródłem prawdy dla wartości liczbowych; literatura jest źródłem dla kontekstu i interpretacji, nie dla wyników tego repozytorium.
